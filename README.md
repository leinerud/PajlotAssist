# PajlotAssist

A menu bar companion for GitHub Copilot, made for designers. Shows your Copilot sessions, their status and step progress, and offers quick actions (open Copilot, folder, editor, branch, PRs).

Reads `~/.copilot` read-only. Build with `./Scripts/build-app.sh` (macOS 14+, Xcode toolchain); the app lands in `build/PajlotAssist.app`.
